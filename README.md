# ☕ Java Fundamentals Portfolio

> Repository dedicated to my Java learning journey, containing exercises, practical examples, and small projects organized by study modules.

## About

This repository brings together my progress in Java fundamentals and essential object-oriented programming concepts.

The project structure is based on the content covered throughout a complete Java course, ranging from programming logic and core language syntax to object-oriented design and other important Java topics.

The main purpose of this portfolio is to document my learning process, reinforce key concepts, and keep practical examples available for review and future reference.

## Project Structure

All source code is organized inside the [`src`](./src) folder, where the content is separated by learning topics.

### Studied Modules

- **Sequential Structure**  
  Exercises focused on input/output, variables, operators, and problem-solving with linear execution flow.

- **Conditional Structures**  
  Practice with decision-making using `if`, `else`, logical operators, and related conditional approaches.

- **Repetitive Structures**  
  Examples using `for`, `while`, and loop control to strengthen logic and problem-solving skills.

- **Object-Oriented Programming**  
  Implementations involving classes, attributes, methods, encapsulation, constructors, and responsibility separation.

- **Memory, Arrays, and Lists**  
  Studies involving arrays, matrices, collections, and in-memory data manipulation.

- **Exception Handling**  
  Exercises focused on error control, `try/catch`, and making applications more robust.

- **File Handling**  
  Examples of reading, writing, and manipulating files, including good resource management practices.

- **Interfaces and Abstraction**  
  Application of contracts, decoupling, and code organization with a focus on extensibility.

- **Inheritance and Polymorphism**  
  Studies involving code reuse, class specialization, and polymorphic behavior.

- **Other Language Topics**  
  Additional content such as dates, composition, lists, and other relevant Java ecosystem features.

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Mateus-F-Moura/Java-Fundamentals-Portfolio.git
   ```

2. Open the project in a Java IDE such as IntelliJ IDEA.

3. Navigate to the `src` folder.

4. Run the files according to the module you want to study.
